# Quarterly study refresh

Maintain this study as Ahmadreza Samadi's original public analysis. Do not start
outreach, collect private property records or turn scenarios into a recommendation.

1. Check official HUD releases/revisions and Census ACS releases/user notes.
   Keep fiscal year, observation year and release edition distinct. First
   publication uses the available source vintage; a later ACS release requires
   a genuine refresh, not silently changing original observations.
2. Download revised public bulk files into a recoverable new source set. Record
   each official URL, retrieval time, bytes and SHA256. Check current reuse terms
   and notices. Never treat a failed download as an empty dataset or retry an
   ambiguous native download without reconciling the completed file.
3. Review changed HUD geography rules and current OMB/Census delineations. Run
   source preparation; examine every missing/extra county, unrecognized code,
   duplicate and suppressed/annotated estimate. The St. Louis exception is
   specific evidence, not a blanket mismatch exemption.
4. Compare complete source populations and coverage with the preceding release.
   Retain all eligible metros; expose exclusions and unresolved values. Preserve
   HUD subareas; do not average them or manufacture property-matched prices.
5. Rebuild the three labelled scenarios and the browser bundle. Assumptions stay
   hypothetical unless a new primary series with reviewed terms is deliberately
   adopted. Record changes to assumptions separately from data changes.
6. Run arithmetic tests, full JS/Python parity, source/output integrity and
   conservation checks. Verify search, edited assumptions, invalid/missing inputs,
   current/fixed CSVs, restored links, print and attributed embeds in native UI.
7. Compare results under identical assumptions and compatible geographies. A
   changed rank/count is not automatically a market trend. Explain source-year,
   area-definition or population changes before making a comparison.
8. Update method, limits, downloadable CSVs, share cover, citation/repository
   version and a concise visible revision note. Retain a reproducible previous
   version; change modification dates only for substantive changes.
9. Integrate narrowly into current website HEAD, run the full current mandatory
   checks, publish and verify actual Pages/IndexNow receipts plus live content.
   Update SEO.md/Brand/CURRENT.md and snapshot. Submission is not indexing proof.
10. Record the release once in the external-action ledger and current STATUS.
    Review referring domains and verified citations separately from deployment.
